# Shaik Akbar // Portfolio

An editorial, responsive personal portfolio website showcasing AI & Data Science coursework at Osmania University, Java Full-Stack engineering, and physical discipline.

## 🚀 Live Preview
Run a local HTTP server:
```bash
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

## 🛠 Tech Stack
- **HTML5 & CSS3**: High-contrast editorial typography, CSS grid & flexbox layouts, responsive design
- **JavaScript (ES6+)**: Smooth anchor navigation and interactive UI elements
- **Typography**: Bebas Neue, Bodoni Moda, Great Vibes, Plus Jakarta Sans
